# Atelier

A modern light & dark theme for FreeScout: neutral ambiances, any accent colour (also per mailbox), fine line icons, readable e-mails in dark mode, light and dark logos, live preview, import / export and updates from GitHub.

- Configure it in **Manage > Settings > Atelier**.
- Update it from **Manage > Modules** (Update button) or from **Settings > Atelier > Updates**.
- Emergency switch: create `storage/app/atelier.disabled` to turn the theme off without touching the module.

Full documentation, screenshots and releases: https://github.com/haugtolas/freescout-atelier
